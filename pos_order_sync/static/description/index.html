POS Session View

Sending Order To Other Active POS
  • After adding products to the cart,if seller want to send this order to any other active POS Session, then seller can click on send button to send this order as quotation.
  • On clicking send button, a popup window will be shown as shown below.Seller can select POS here and send quotation as well as print quotation details. On clicking 'Send and Print' button, quotation will be send and quotation receipt will be generated automatically.
  • This message will be shown, if order is successfully sent to other session.
    • Loading Received Orders
  • To load quotations(orders) that are sent by other POS Session to current running POS Session, click on load button. To update quotation list at any time, click on refresh button as shown below. If any quotation(order) is available to load for current running session then load button will be highlighted automatically
  • Seller can Filter quotation on the basis of quote id,customer and load quotation by click on quotation.
    • Order Loaded
    Quotation History
  • Click this button to see history and state of all those quotations that are sent by current running POS Session.
  • This history popup will be shown on click history button.Seller can see state of all those quotations that are sent by his POS Session.

    • Backend View

    Configuration for quotation receipt
  • Select between the option to print quotation in pdf format or in POSBOX receipt.
    • Backend View of Saved Quotation
  • After creating quotation in POS session,quotation is also saved in backend as shown below.

    Below is the list of features odoo Pos Order Sync

    Send Quotations Between POS Sessions

    • Easily send POS sales quotations from one live POS session to another.
    • Enables seamless communication between different POS terminals.

    Add Internal Notes to Quotations

    • Include helpful internal notes along with the sent quotations.
    • Enhances communication and provides extra context for the receiving POS user.

    Check the Status of Sent Quotations

    • The sender can check the status of the sent quotations from their POS session.
    • Provides real-time visibility into the progress of orders between POS terminals.

    Detailed Quotation History

    • Access history of all sent quotations, including their current status and destination POS.
    • Offers insights into the flow of orders and facilitates better order management.

    Filter Quotations for Quick Access

    • Filter quotations based on quote ID, customer, or other relevant criteria.
    • Streamlines the process of finding and loading specific orders.

    Floor and Table Selection for Restaurant POS

    • Select specific floors and tables when sending orders between POS sessions in restaurant.
    • Tailored for restaurants, optimizing order management in busy settings.

    Flexible Quotation Printing Options

    • Option to print quotations automatically upon sending for easy documentation.
    • Adds convenience and ensures proper record-keeping for each transaction.

    Real-Time Status Updates with Clock Icon

    • Track the status of sent orders in real-time using the clock icon.
    • Stay updated on order progress within the POS session.

    Efficient Queue Management for Happy Customers

    With Odoo POS Order Sync, long queues and overwhelmed POS sessions are a thing of the past. It ensures smooth operations by synchronizing orders between multiple POS sessions. This not only reduces queue abandonment but also distributes the workload effectively. This prevents potential sales loss during peak times or holidays.
    Sending sales quotations between live POS sessions elevates customer experience. It makes sure orders keep flowing seamlessly.

    Enhanced Customer Experience in Every Order

    The module allows POS users to send quotations between live sessions. By doing so, businesses can eliminate unnecessary wait times. This results in reduced queue abandonment and prevents potential customers from seeking alternatives. It empowers businesses with internal notes and status checks ensuring swift service. This results in customer loyalty and positive brand perception.

    Flexible and Adaptable for Diverse Business Needs

    It is a versatile solution that adapts to various business scenarios. For restaurants, retail, or diverse customer demands, this module flexibly manages orders. Synchronizing live POS sessions helps businesses handle high traffic and distribute work efficiently. Also, they provide a seamless experience for both customers and staff. Quotation history viewing and note addition enhance customer service and operational efficiency.
